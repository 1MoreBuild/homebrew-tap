# homebrew-tap

Homebrew tap for `1MoreBuild` apps and CLI tools.

## Install

### Lane

```bash
brew install --cask 1MoreBuild/tap/lane
```

### byr-pt-cli

```bash
brew tap 1MoreBuild/tap
brew install byr-pt-cli
```

Or one-liner:

```bash
brew install 1MoreBuild/tap/byr-pt-cli
```

## Available Formulae

- `byr-pt-cli`

## Available Casks

- `lane`

## Upgrade

```bash
brew update
brew upgrade --cask lane
brew upgrade byr-pt-cli
```
